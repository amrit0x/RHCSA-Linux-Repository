# RHCSA — DNF Package Management

DNF (Dandified YUM) is the package manager used to install, update, remove and manage RPM software packages in RHEL.

- Automatically resolves dependencies from available repositories.
- Works with online and offline repositories.
- On RHEL 9, `yum` is a compatibility command for DNF.

The current RHCSA EX200 objectives specifically require configuring RPM repositories and installing, updating and removing RPM packages.

## 1. Essential DNF Commands

**Package Management :**

| Command | Purpose |
| --- | --- |
| `dnf install httpd` | Install package |
| `dnf remove httpd` | Remove package |
| `dnf update httpd` | Update package |
| `dnf update` | Update all installed packages with available updates |
| `dnf install -y httpd` | Install without confirmation prompt |
| `dnf install ./file.rpm` | Install a local RPM file |

---

**Search and Verify Packages :**

| Command | Purpose |
| --- | --- |
| `dnf search httpd` | Search packages by keyword |
| `dnf info httpd` | Show package details |
| `dnf list --installed` | List installed packages |
| `dnf list --installed httpd` OR `dnf list installed httpd`  | Check whether httpd is installed |
| `dnf provides /usr/bin/ls` | Find which package provides a file |

### Repository Management

| Command | Purpose |
| --- | --- |
| `dnf repolist` | List enabled repositories |
| `dnf repolist --all` | List enabled and disabled repositories |
| `dnf clean all` | Clear cached repository data |
| `dnf makecache` | Download/refresh repository metadata |

## 2. Important Configuration Files

| File / Directory | Purpose |
| --- | --- |
| `/etc/yum.repos.d/` | Stores `.repo` repository configuration files |
| `/etc/dnf/dnf.conf` | Main DNF configuration |
| `/var/cache/dnf/` | DNF cache location on RHEL 9 |

Remember: DNF normally reads repository configuration from `.repo` files under `/etc/yum.repos.d/`.

## 3. Configure DNF Repositories

MOST IMPORTANT PRACTICAL SKILL

**A. Remote Repository**

Create a repository configuration file:

```bash
vim /etc/yum.repos.d/exam.repo
```

Add:

```
[BaseOS]
name=BaseOS Repository
gpgcheck=0
enabled=1
baseurl=http://server.example.com/BaseOS

[AppStream]
name=AppStream Repository
gpgcheck=0
enabled=1
baseurl=http://server.example.com/AppStream
```

The URLs are placeholders. Replace them with the actual URLs supplied in your lab or task.

`gpgcheck=0` is shown for a trusted, isolated practice repository only. In normal administration, use `gpgcheck=1` with a trusted GPG key.

**B. Local Repository (ISO/DVD)**

If your RHEL installation ISO is mounted at `/mnt/iso`:

```
[BaseOS]
name=Local BaseOS
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-redhat-release
enabled=1
baseurl=file:///mnt/iso/BaseOS

[AppStream]
name=Local AppStream
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-redhat-release
enabled=1
baseurl=file:///mnt/iso/AppStream
```

This example assumes the RHEL installation media and the indicated GPG key are present. Make sure the ISO is mounted and remains accessible after reboot.

### Important Repository Options

| Option | Meaning |
| --- | --- |
| `[BaseOS]` | Unique repository ID |
| `name=` | Repository display name |
| `baseurl=` | Repository location |
| `enabled=1` | Enable repository |
| `enabled=0` | Disable repository |
| `gpgcheck=1` | Enable RPM signature checking |
| `gpgkey=` | Trusted signing key location |

URL types:

- `file:///` → Local repository
- `http://` → Remote repository
- `https://` → Secure remote repository

### Verify Repository:

```
dnf clean all
dnf repolist
dnf makecache
```

Test installation:

```
dnf install httpd
rpm -q httpd
```

## 4. Troubleshooting

| Error | What to check |
| --- | --- |
| `There are no enabled repositories` | Repository configuration and `enabled=1` |
| `Failed to download metadata` | Repository URL, networking or ISO mount |
| `No match for argument` | Package name and repository contents |
| `GPG check FAILED` | Package signature and trusted GPG key |

Useful checks:

```
dnf repolist
dnf clean all
dnf makecache
```
